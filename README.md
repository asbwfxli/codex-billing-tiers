换句话说，Codex Credits 是"加量包"，不是"开通包"。没有 Plus/Pro，你连买它的资格都没有。

## Codex 需要什么套餐？先看清额度层级

免费版 ChatGPT 可以聊天，但 Codex 的能力（桌面应用、Cloud 任务、多 agent 并行）基本要靠付费套餐才跑得动。额度层级大致是这样：

- **免费版 / Go**：Codex 里额度极少。有第三方整理的 Codex 订阅指南直接写明，Go 在 Codex 中的表现和 Free 没有区别。
- **Plus（官方 $20/月）**：Codex 的完整访问，对大多数个人开发者是够用的起点。
- **Pro 100 美元档（约 5x）**：相对 Plus 约 5 倍用量，适合每天用但不是全天重负载的人。
- **Pro 200 美元档（约 20x）**：约 20 倍用量，适合多个项目并行、持续跑 agent 的场景。

这里有个容易误读的地方：5x 和 20x 说的是相对 Plus 的用量定位，不是模型聪明 5 倍或 20 倍。两档 Pro 的核心能力相同，差别在额度。另外单个模型可能有独立额度，用完之后要等页面显示的重置时间，账号里其他模型还能继续用。页面上的 Unlimited 也受合理使用和防滥用规则约束，不能理解成可以无限并发或转售。

两件需要提前知道的事。一是 Pro 20x 目前对普通新订阅和升级仍有额外限制，有第三方整理的资料提到符合条件的老用户可能拿到一次恢复订阅的机会——如果你想从 Plus 升上去，先确认自己有没有购买资格，别为了切换方案把还在有效期内的订阅取消掉。二是地区问题：有第三方在 2026 年 8 月的核验指出，OpenAI 的 ChatGPT 支持地区列表里没有中国大陆。官方对从未支持地区访问或提供访问可能导致账号被暂停或封禁有明确说明，这一点和你用不用第三方平台无关。
